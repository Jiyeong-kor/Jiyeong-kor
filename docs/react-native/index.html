Kotlin·Jetpack Compose Android 개발자를 위한 과정

Android 개발 경험을
React Native로 확장합니다

이 과정은 Kotlin과 Jetpack Compose로 Android 화면, 상태, 네트워크 기능을 구현해 본 개발자를 대상으로 합니다. JavaScript, TypeScript, React와 React Native는 처음이라고 가정합니다. 이미 익숙한 Android 기초를 반복하기보다 React Native에서 달라지는 렌더링, 상태, UI, 네이티브 경계를 집중적으로 학습합니다.

Kotlin Jetpack Compose Coroutine Gradle·Android Studio

이 과정의 전제와 범위

아래 전제를 충족하는 개발자가 1강부터 순서대로 학습하도록 구성했습니다.

이미 알고 있다고 보는 내용

Kotlin 문법과 컬렉션, Compose의 상태와 기본적인 부수 효과, Coroutine, Gradle, Android 생명주기와 화면 이동의 기초입니다.

처음부터 배우는 내용

JavaScript와 TypeScript, React 렌더링과 Hook, React Native UI와 레이아웃, Expo, Metro, Hermes, New Architecture를 설명합니다.

완료할 수 있는 범위

React Native 화면과 앱 구조를 구현하고, Kotlin 기능을 연결하며, 테스트와 Android release 빌드까지 수행합니다. 프로그래밍 입문이나 웹 React 일반 과정은 다루지 않습니다.

학습 현황

완료 표시와 문제 풀이 기록은 현재 브라우저에 저장됩니다. 다른 기기로 옮길 때에는 진도 파일을 사용합니다.
