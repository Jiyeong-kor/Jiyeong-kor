이 사이트에서 공부하는 방식

공식 문서를 외부에서 먼저 읽어 오도록 떠넘기지 않습니다. 교과서 본문에서 필요한 내용을 가르친 뒤 원문을 검증 자료로 제공합니다.

1. 개념을 한국어로 학습합니다

새 용어를 정의하고 왜 필요한지 설명합니다. Compose에서 이미 알고 있는 개념과 같아 보이지만 실제로 다른 지점을 명확히 구분합니다.

2. 코드와 상태 흐름을 확인합니다

TypeScript, TSX, Kotlin 예제를 함께 읽고 렌더링, 수명주기, 스레드, 네이티브 경계를 실제 코드로 연결합니다.

3. 문제와 실습으로 검증합니다

각 단원에서 바로 확인 문제를 풀고 개인 구현과 팀 토론을 진행합니다. 마지막에는 기존 Compose 앱의 기능을 React Native로 포팅합니다.

프로젝트 시작 기준

신규 팀 실습 앱과 기존 Android 앱 통합은 시작 방식이 다릅니다.

신규 팀 실습 앱

Expo 프로젝트와 Development Build를 사용합니다. 파일 기반 라우팅, 개발 빌드, 네이티브 모듈과 출시 도구를 단계적으로 학습합니다.

기존 Kotlin 앱에 일부 기능 추가

React Native Community 구조를 기존 Gradle 프로젝트에 통합합니다. Android가 진입과 종료를 소유하고 React Native가 기능 내부 흐름을 담당합니다.

Kotlin 기능 재사용

TypeScript Codegen 명세와 Turbo Native Module을 사용합니다. 실제 네이티브 UI는 Fabric Native Component로 연결합니다.
