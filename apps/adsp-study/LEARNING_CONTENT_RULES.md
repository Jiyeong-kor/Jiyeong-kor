# ADsP 학습 콘텐츠 작성 규칙

이 규칙은 ADsP 학습 페이지의 이론, 문제와 해설을 생성하거나 수정할 때 반드시 적용합니다.

## 1. 개념을 문제보다 먼저 설명합니다

- 문제와 보기에 등장하는 모든 새 용어는 해당 모듈 이론에서 먼저 정의합니다.
- 새 개념에 선행 개념이 필요하면 선행 개념부터 순서대로 설명합니다.
- 사용자가 문제를 풀었다는 사실만으로 개념을 이해했다고 간주하지 않습니다.
- 설명되지 않은 개념을 맞히지 못한 결과는 사용자의 지식 부족으로만 판정하지 않습니다.

## 2. 시험에 나오는 실제 용어를 보존합니다

- 영문 용어는 `영문 풀네임 → 단어 뜻 → 한국어 시험 용어 → 사용 이유와 원리` 순서로 설명합니다.
- 약어는 첫 등장 때 반드시 풀어 씁니다. 예: `VIF(Variance Inflation Factor, 분산팽창계수)`.
- `F1 Score`, `Support Vector Machine`, `Odds Ratio`, `Autocorrelation Function`처럼 시험에서 영문으로 나올 수 있는 용어를 한국어 표현으로만 바꾸지 않습니다.
- Association Rule의 `Confidence`는 공식 지표이므로 영문과 한국어 명칭을 함께 씁니다. 주관적 자신감 측정과 혼동하지 않습니다.

## 3. 한자어의 뜻을 풉니다

- 귀무가설, 잔차, 분산, 정상성, 군집처럼 한자 의미가 이해에 도움이 되는 용어는 한자를 함께 제시합니다.
- 각 글자의 뜻과 용어 전체가 만들어진 이유를 자연스러운 한국어로 설명합니다.

## 4. 공식은 변수와 계산 과정을 함께 설명합니다

- 공식만 적지 않고 각 기호가 무엇인지 정의합니다.
- 분모와 분자의 의미를 구분합니다.
- 최소 한 개의 숫자 계산 예시를 제공합니다.
- Support, Confidence, Lift처럼 혼동하기 쉬운 공식은 같은 사례로 연속 계산합니다.

## 5. 해설은 연결 오류를 교정합니다

- 정답인 이유를 설명합니다.
- 오답이 되기 쉬운 개념 연결을 함께 지적합니다.
- 정답 문장만 반복하지 않고, 해당 문제에서 적용한 선택 기준이나 계산 과정을 다시 제시합니다.

## 6. 정답 위치를 균등하게 배치합니다

- 전체 문항의 정답 위치를 1·2·3·4번에 최대한 균등하게 배치합니다.
- 같은 정답 번호가 세 번 이상 연속되지 않게 합니다.
- 정답 위치 패턴만으로 답을 추측할 수 없도록 자동 검증합니다.

## 7. 학습 결과는 지식 확인에만 사용합니다

- 자신감, 기분과 체감 난이도를 측정하지 않습니다.
- 첫 답안, `모르겠음`, 정답 여부, 해설 확인 여부와 메모만 저장합니다.
- 개인 답안, 메모, 학습 시각과 결과 파일명은 공개 저장소에 포함하지 않습니다.

## 8. 화면은 기기에 맞게 가용 폭을 사용합니다

- 모바일은 한 열, 태블릿과 PC는 가용 폭에 맞춘 다열 레이아웃을 사용합니다.
- 이론 문단과 문제 문장은 카드 내부 너비를 불필요하게 제한하지 않습니다.
- 표와 코드는 필요할 때만 가로 스크롤을 허용합니다.
