# 한능검 1급 훈련소

한국사능력검정시험 심화에서 80점 이상을 목표로 하는 정적 웹 학습 도구입니다.

## 공개 주소

- GitHub Pages: `https://jiyeong-kor.github.io/Jiyeong-kor/history/`
- 기존 ADsP 페이지와 React Native 과정은 변경하지 않고 `docs/history/`에서 독립적으로 배포합니다.

## 품질 개편 기준

기존 2,400문항은 넓은 개념 120개를 단순 형식에 넣어 반복했고, 정답 명칭 노출·무관한 시대의 오답·대표 연도만 비교하는 연대기 문제가 생길 수 있었습니다. 현재 버전은 다음 방식으로 다시 구성했습니다.

- 복합 주제를 분리한 핵심 개념 127개
- 모든 개념을 한 번씩만 배치한 40개 학습 단원
- 같은 시대와 인접 주제만 연결하는 혼동 개념 묶음 21개
- 선후 관계를 별도로 검토한 연대기 묶음 11개
- 정답 문구가 자료에 직접 노출되는 문항 자동 차단
- 같은 의미가 겹치는 오답 단서를 줄이는 단어 중복 검사
- 한 모의고사 안에서 동일 개념 반복 금지
- 다섯 모의고사 사이에서 동일 문항 반복 금지

## 현재 콘텐츠

- 핵심 개념: 127개
- 학습 단원: 40개
- 핵심 문항: 1,270개
- 심화 반복 문항: 1,270개
- 전체 훈련 문항: 2,540개
- 고정형 전 범위 모의고사: 5회, 총 250문항
- 모든 문항: 5지선다형, 단일 정답, 다섯 선택지별 해설
- 모의고사: 회차당 50문항, 80분, 100점
- 공식 평가 유형: 여섯 유형 모두 포함
- 학습 기록: 브라우저 로컬 저장과 JSON 내보내기·불러오기

2,540문항은 2,540개의 독립 원고를 각각 수작업한 문제가 아닙니다. 127개의 정리된 핵심 개념에 열 개의 핵심 문항 형식과 열 개의 심화 반복 형식을 적용합니다. 핵심 문항과 반복 문항은 화면에서 명확히 구분합니다. 고정 모의고사는 핵심 문항만 사용합니다.

## 근거와 참고 범위

- 국사편찬위원회의 심화 시험 형식과 여섯 가지 공식 출제 유형을 문항 분류에 사용합니다.
- 우리역사넷, 한국사데이터베이스, 국가유산포털, 한국독립운동정보시스템과 국가기록원 자료를 역사 사실의 우선 근거로 사용합니다.
- 최태성 선생님의 공개 강의와 공개된 교재 목차에서 전체 시대 흐름과 40강 학습 구조를 참고했습니다.
- 강의와 교재의 문장·판서·문제·이미지는 복제하지 않았습니다.

## 난도 표시

쉬움·보통·어려움 표시는 문항 형식에 필요한 추론 단계에 따라 부여합니다. 실제 응시자 정답률을 측정한 문항 모수는 아닙니다. 배점은 쉬움 1점, 보통 2점, 어려움 3점으로 계산합니다.

## 검증

저장소 루트에서 다음 명령을 실행합니다.

```bash
node scripts/verify_history_site.mjs
```

GitHub Actions는 최종 정적 파일을 대상으로 같은 검증 스크립트를 다시 실행합니다.

검증 스크립트는 다음 항목을 확인합니다.

- 필수 정적 자산과 서비스 워커 캐시 목록
- 반응형 레이아웃, 다크 모드와 자산 버전 일치
- 127개 핵심 개념의 필수 필드, 네 개 단서와 공식 출처
- 40개 단원의 중복 없는 전체 개념 배치
- 혼동 개념 묶음과 연대기 묶음의 참조·순서
- 2,540개 문항의 고유 ID와 내용 중복
- 문항별 다섯 고유 선택지, 단일 정답과 선택지별 해설
- 자료 속 정답 명칭 직접 노출 여부
- 핵심 오답이 같은 시대의 인접 개념으로 구성되는지 여부
- 핵심 1,270문항과 심화 반복 1,270문항의 분리
- 다섯 고정 모의고사의 50문항·100점·난도 배분
- 모의고사별 전 시대 배분과 공식 평가 유형 포함
- 모의고사 사이 250문항의 완전한 비중복
- 제79회 시험일 2026년 8월 9일 반영 여부

## 개인정보와 저작권

- 답안, 오답, 북마크와 진행 중인 시험은 사용자의 브라우저에만 저장합니다.
- 사용자가 직접 내보낸 JSON 파일 외에는 학습 기록을 서버로 전송하지 않습니다.
- 이 프로젝트는 국사편찬위원회, 최태성 선생님 또는 이투스와 공식 제휴하지 않았습니다.
- 실제 기출문제와 유료 교재의 문장·이미지를 복제하지 않습니다.
- 시험 일정과 규정은 한국사능력검정시험 공식 홈페이지를 최종 기준으로 확인해야 합니다.
