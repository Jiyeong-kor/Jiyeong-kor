# 한능검 1급 훈련소

한국사능력검정시험 심화에서 1급을 목표로 하는 정적 웹 학습 도구입니다.

## 공개 주소

- GitHub Pages: `https://jiyeong-kor.github.io/Jiyeong-kor/history/`
- 기존 ADsP 페이지와 React Native 과정은 변경하지 않고 `docs/history/`에 독립 배포합니다.

## 학습 설계

- 국사편찬위원회가 제시하는 심화 시험 형식과 여섯 가지 평가 유형을 문제 분류에 사용합니다.
- 최태성 선생님의 공개 강의와 공개된 2026 별별한국사 도서 정보에서 큰 흐름 정리, 핵심 판서, 능동 회상, 반복 문제 풀이 구조를 참고했습니다.
- 교재 문장·문제·판서·이미지를 복제하지 않았습니다.
- 역사 사실은 우리역사넷, 국가유산포털, 독립기념관 한국독립운동정보시스템, 국가기록원 등 공공기관 자료를 우선 근거로 사용합니다.

## 문제은행 구조

- 핵심 개념: 110개
- 개념별 문항 변형: 20개
- 전체 문항: 2,200개
- 선택지: 문항마다 5개
- 해설: 정답과 오답 선택지 모두 제공
- 실전 모의고사: 50문항, 80분, 100점

2,200개 문항은 2,200개의 수동 원고를 그대로 저장한 구조가 아닙니다. 110개의 검토된 핵심 개념과 단서를 기반으로 자료 추론, 옳은 선지, 옳지 않은 선지, 연결 판단, 시대 판단, 전후 관계, 순서 배열, 상황 추론 형식을 결정적으로 조합합니다. 같은 문항 ID는 항상 같은 선택지와 정답을 생성합니다.

## 공개 화면 원칙

공개 화면에는 학습자가 문제를 풀고 이해하는 데 필요한 정보만 표시합니다.

- 개념과 핵심 단서
- 문제, 정답, 선택지별 해설
- 실제 풀이 진도와 오답
- 공식 출처 포털
- 시험 일정과 채점 기준

문제 생성 규칙, 배포 절차, 브랜치 정보와 검증 구현은 학습 화면에 노출하지 않습니다.

## 학습 기록과 개인정보

- 답안과 오답 기록은 브라우저 `localStorage`에만 저장합니다.
- 사용자가 직접 내보낸 JSON 파일 외에는 서버로 학습 기록을 전송하지 않습니다.
- 미응답 문항은 풀이 완료나 진도에 포함하지 않습니다.
- JSON 가져오기와 내보내기로 기기 간 기록을 옮길 수 있습니다.

## 배포 자산

```text
docs/history/
├─ index.html                    # 압축 학습 화면 로더
├─ manifest.webmanifest          # 설치형 웹앱 정보
├─ sw.js                         # 오프라인 캐시
├─ icon.svg                      # 웹앱 아이콘
└─ payload/
   └─ part-*.gz.b64              # 압축된 학습 화면의 분할 자산
```

`payload/` 파일을 순서대로 결합하고 Base64 디코딩과 Gzip 해제를 거치면 개념·문제은행·스타일·애플리케이션 코드가 포함된 단일 학습 HTML이 복원됩니다.

## 검증

저장소 루트에서 다음 명령을 실행합니다.

```bash
node scripts/verify_history_site.mjs
```

검증 스크립트는 다음 항목을 확인합니다.

- 압축 학습 자료의 결합과 복원
- 필수 배포 자산과 반응형·다크 모드 구성
- 핵심 개념 110개의 필수 필드와 고유 단서
- 2,200개 문항의 고유 ID
- 각 문항의 5개 고유 선택지와 단일 정답
- 선택지별 해설과 공식 평가 유형
- 50문항·100점 모의고사 구성
- 학습자 화면과 제작자용 정보의 경계

## 저작권과 운영 주체

이 프로젝트는 국사편찬위원회, 최태성 선생님, 이투스와 공식 제휴하지 않았습니다. 공식 시험 문제와 유료 교재의 문장·이미지를 복제하지 않습니다. 시험 일정과 규정은 한국사능력검정시험 공식 홈페이지를 최종 기준으로 확인해야 합니다.
