# 한능검 1급 훈련소

한국사능력검정시험 심화에서 80점 이상을 받아 1급을 취득하도록 설계한 정적 웹 학습 도구입니다.

## 공개 주소

- GitHub Pages: `https://jiyeong-kor.github.io/Jiyeong-kor/history/`
- 기존 ADsP 페이지와 React Native 과정은 변경하지 않고 `docs/history/`에서 독립적으로 배포합니다.

## 학습 설계

- 국사편찬위원회가 제시하는 심화 시험 형식과 여섯 가지 평가 유형을 문항 분류에 사용합니다.
- 최태성 선생님의 공개 강의와 공개된 교재 소개에서 큰 흐름 정리, 핵심 단서 반복, 능동 회상 방식을 참고했습니다.
- 강의와 교재의 문장·판서·문제·이미지는 복제하지 않았습니다.
- 역사 사실은 우리역사넷, 한국사데이터베이스, 국가유산포털, 한국독립운동정보시스템, 국가기록원 자료를 우선 근거로 확인합니다.

## 현재 콘텐츠

- 검토된 핵심 개념: 120개
- 개념별 결정적 문항 변형: 20개
- 전체 예상 문항: 2,400개
- 모든 문항: 5지선다형, 단일 정답, 다섯 선택지별 해설
- 실전 모의고사: 50문항, 80분, 100점
- 공식 평가 유형: 여섯 유형 모두 포함
- 학습 기록: 브라우저 로컬 저장과 JSON 내보내기·불러오기

2,400개 문항은 2,400개의 수동 원고를 각각 저장한 구조가 아닙니다. 120개의 핵심 개념과 네 개의 단서를 자료 추론, 지식 확인, 오답 선지 판별, 시대 판단, 연대기 배열, 상황 판단, 탐구 설계, 결론 도출 형태로 결정적으로 조합합니다. 같은 문항 ID는 항상 같은 선택지와 정답을 생성합니다.

## 배포 구조

```text
docs/history/
├─ index.html
├─ styles.css
├─ data.js
├─ app.js
├─ manifest.webmanifest
├─ sw.js
└─ icon.svg
```

압축된 Base64 조각을 실행 시점에 결합하는 방식은 사용하지 않습니다. 일반 정적 파일을 그대로 배포하기 때문에 배포 자산의 손상 여부를 파일 단위로 확인할 수 있습니다.

## 검증

저장소 루트에서 다음 명령을 실행합니다.

```bash
node scripts/verify_history_site.mjs
```

검증 스크립트는 다음 항목을 확인합니다.

- 필수 정적 자산과 서비스 워커 캐시 목록
- 반응형 레이아웃과 다크 모드
- 핵심 개념 120개의 필수 필드와 네 개의 고유 단서
- 예상 문항 2,400개의 고유 ID
- 문항별 다섯 개의 고유 선택지와 단일 정답
- 다섯 선택지별 해설, 난도, 배점, 공식 평가 유형
- 50문항·100점 모의고사 구성
- 제79회 시험일 2026년 8월 9일 반영 여부

## 개인정보와 저작권

- 답안, 오답, 북마크와 진행 중인 시험은 사용자의 브라우저에만 저장합니다.
- 사용자가 직접 내보낸 JSON 파일 외에는 학습 기록을 서버로 전송하지 않습니다.
- 이 프로젝트는 국사편찬위원회, 최태성 선생님, 이투스와 공식 제휴하지 않았습니다.
- 시험 일정과 규정은 한국사능력검정시험 공식 홈페이지를 최종 기준으로 확인해야 합니다.
